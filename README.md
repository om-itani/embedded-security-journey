# Omar Itani — Embedded Security Engineering Journey

## 👋 Who I Am

I'm Omar! I'm currently studying Computer and Network Engineering, and I enjoy finding the ins and outs of how things work — from taking things apart ever since I was little, to working on electronic projects on my car. I believe that anything is possible if you have the right tools.

## 🎯 What This Repo Is

This repo is a self-reflection, a promise, a trust I'm making to myself that I will one day be an amazing embedded product security engineer. I will learn from every mistake I make along the way, keeping a daily record of what worked, what didn't, and how it all fits together.

## 🛤️ Where I'm Going

I want to gain enough experience to confidently apply to electronics internships and actually know what I'm doing rather than being headless. My dream job is to be an Embedded Product Security Engineer, but life is full of doors and opportunities, so I'll go wherever the road leads.

This is what I have at my disposal — thanks to AliExpress 😅

**Microcontrollers** — the brains of the projects I'll be working on:
- Arduino UNO R3
- ESP32 DevKitC-32

- ATMEGA32A-PU

**Tools** — the magic tools I've collected over the years:
